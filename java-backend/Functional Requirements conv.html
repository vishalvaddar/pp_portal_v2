19. Technology Stack
The system shall be built using:
•
Frontend: React.js
•
Backend: Node.js with Express.js
•
Database: PostgreSQL (use standard SQL features only, avoid stored procs, UDFs and
triggers)
•
Should use only open-source, free libraries. No proprietary, commercial libraries
should be used without seeking prior approval of management.
